安装：`npm ci`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:18112 。

## 并置研究空间

从「我的收藏」进入「并置研究」，可把收藏中的两到四件作品带进一个可行走的研究空间：

- **同一尺度**：每件作品按登记的厘米尺寸 1:1 呈现，主展厅、作品档案与研究空间使用同一比例；墙面不足时分成两组，不缩小任何一件。
- **观看距离**：每件作品给出自己的建议站位（按画幅对角线估算），分组时另给组视图距离。地面上的标线对应组视图距离。
- **导览暂停**：进入研究空间会把主展厅的主题导览暂停在原来的站点，返回后按「继续」从原处接着走，讲解也回到原段落。
- **讲解**：可以单独听当前作品，也可以只播这一段；切到另一件时播放器停止，但比较笔记不会丢失。
- **同段对照**：按段落序号依次播放各件作品的同一段。缺少该段的作品会被标注为未参与，不会用别的段落顶替。
- **贴图策略**：`按需细化` 为全部作品保留低精度共享贴图，只为当前走近的作品提升一张高精度贴图（切换时先释放上一张）；`流畅对照` 提高共享精度、取消切换加载。两种策略都不改变画面尺寸、取景或观看距离，面板会显示估算显存。
- **笔记隔离**：单件收藏感想（按作品保存）、比较笔记（按作品组合保存）与导览位置各自独立；移除讲解中的作品、加入缺少同段的作品、或退出后重新进入，都不会互相覆盖。回顾文件只记录比较关系，不把并置过程重复计入参观时长。
